# Pip's Dream Terminal

A tiny, responsive portfolio for Pip, Junior Dream Engineer at the Midnight Nursery. Built with plain HTML, CSS, and JavaScript so it can be deployed as a static site.

## Run it

Open `index.html` in a browser, or publish this folder with GitHub Pages, Netlify, Vercel, or Cloudflare Pages. No build step is required.

## What is included

- Pip's identity and three project cards: Lullaby Lab, Nightlight Shelf, and Dream Delivery Routes.
- A three-scene origin story with scroll progress.
- Pointer-following eyes, day/night mood, Web Audio lullaby and mute control.
- Clickable block tower, local wish wall, per-browser visit odometer, sparkle trail, and hidden five-tap smile surprise.
- Responsive layout, keyboard-accessible toy reset, reduced-motion support, and local-only storage for wishes and visit count.

## Publish and submit

1. Create a public GitHub repository and upload `index.html`, `style.css`, `app.js`, and `README.md` to its root. Make your sprint commits visible.
2. Enable GitHub Pages or deploy the repository with another static host.
3. Submit the deployed site, public repository, short build story, and credits in the official haX.baby workspace by **19 October 2026, 17:17 IST**.

The official event brief permits AI coding tools and requires source credits. Pip is drawn with CSS; no external character image or audio file is used. Typography uses Google Fonts: Fraunces, DM Sans, and DM Mono. The lullaby is synthesized in-browser with the Web Audio API. Character canon and challenge: haX.baby, Track 1: Pip the Skull Baby.

## Short build story

Pip's Dream Terminal imagines a portfolio as the working desk of a Junior Dream Engineer. The warm, scrapbook-like interface borrows the playful spirit of the early web while giving Pip's projects room to feel alive: visitors can hear a tiny lullaby, follow a rooftop delivery route, change the nursery light, and build a block tower during a break. A three-part story follows Pip from a rainy midnight arrival to a first music-box invention and tonight's dream deliveries. The wish wall and visit counter are saved only in the visitor's browser; there is no shared guestbook or tracking server.
